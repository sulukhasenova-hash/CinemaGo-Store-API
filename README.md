# CinemaGo Store + PHP Data API

Учебный интернет-магазин дисков, билетов и кино-товаров. Проект разделён на два PHP-компонента:

- `shop/` — интерфейс, PHP-сессии, HTTP-клиент, расчёт и сортировка рекомендаций.
- `api/` — отдельный PHP API, PDO + SQLite, авторизация, каталог, матрицы и история событий.

SQLite-файл создаётся при инициализации и находится в `api/storage/`, вне публичной папки API.

## Требования

- XAMPP с PHP 8.x и расширениями `curl`, `pdo_sqlite`, `sqlite3`.
- Apache для магазина.
- PHP CLI для отдельного API-сервиса.

Проверка модулей в Windows:
```powershell
C:\xampp\php\php.exe -m
```
В списке должны быть `curl` и `pdo_sqlite`.

## Запуск

1. Распакуйте папку `CinemaGo_Store_API` в `C:\xampp\htdocs\`.
2. Откройте `api/config.php` и `shop/config.php`. В обоих файлах должен быть одинаковый `API_TOKEN`. Для учебного проекта уже задан один тестовый токен; перед публикацией замените его на случайный секрет.
3. Один раз создайте учебную SQLite-базу:
```powershell
cd C:\xampp\htdocs\CinemaGo_Store_API\api
C:\xampp\php\php.exe setup.php
```
4. Запустите Apache в XAMPP.
5. В отдельном терминале запустите API:
```powershell
cd C:\xampp\htdocs\CinemaGo_Store_API\api
C:\xampp\php\php.exe -S 127.0.0.1:8081 -t public
```
Терминал с API оставьте открытым.
6. Откройте магазин: `http://localhost/CinemaGo_Store_API/shop/`

## Структура

- `shop/` — PHP-магазин. В нём нет подключения к SQLite и SQL-запросов.
- `api/public/v1/` — маршруты API.
- `api/src/` — внутренняя логика доступа к данным.
- `api/storage/` — SQLite (создаётся setup.php).
- `api/setup.php` — создание и заполнение учебной базы.
- `docs/API.md` — контракт API.
- `docs/TESTS.md` — 11 ручных проверок по заданию.

## Важно

Это учебный демонстрационный магазин: оплата билетов и заказов не проводится, банковские данные не запрашиваются. Цены и товары демонстрационные. Не используйте проект для реальных платежей без отдельной платёжной интеграции и мер безопасности.
